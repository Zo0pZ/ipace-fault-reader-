I-Pace Fault Reader

Reads fault codes and battery data through your Veepeak OBDCheck BLE adapter.

Read-only by default. Everything except the separate "Clear fault codes" section only reads. The app never changes settings or updates software, and it refuses any other kind of command. If the car shows a high-voltage warning telling you not to charge or drive, follow that first.

1. Connect

Plug the adapter into the OBD port (under the dashboard, driver's side, above the pedals). Turn the car on (press the start button without your foot on the brake). Then tap Connect and pick the adapter from the list. Don't pair it in Android's Bluetooth settings.

Not connected

2. Read fault codes

Asks each module for its stored fault codes, then for the snapshot the car saved when each code was set.

3. Battery readings

4. Watch while plugging in

Start watching, wait for one or two readings, then plug the charging cable in. The app records battery values and checks the battery and charger modules for new faults every few seconds, so you can see exactly when the charge fails. Keep the screen on.

    5. Save the report

    Saves everything above as a text file you can send to the garage, alongside a full log.

    6. Clear fault codes (advanced)
    Read this first. Clearing deletes the stored codes and their snapshots. Jaguar uses that history to diagnose the fault, so save or share a report first. Clearing does not repair anything. If the fault is still there, the code will come back, often straight away or when you next plug in. Do not keep clearing a high-voltage warning so you can drive or charge.

    Clears codes in one module only, then reads it again so you can see what comes back.
